# Hotel Reservation System

## Description

Hotel Reservation System is a Java-based application designed to manage hotel room bookings efficiently. The system allows users to view room availability, book rooms, cancel reservations, and simulate payment processing through a menu-driven interface.

## Features

* View available rooms
* Room categorization (Standard, Deluxe, Suite)
* Book hotel rooms
* Cancel reservations
* Payment simulation
* Display booking status
* Menu-driven console application

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Eclipse IDE

## Concepts Implemented

* Classes and Objects
* Encapsulation
* Methods
* Loops
* Conditional Statements
* Collections Framework (ArrayList)

## How to Run

1. Open the project in Eclipse.
2. Run the `HotelReservationSystem.java` file.
3. Choose options from the menu to manage room bookings.
