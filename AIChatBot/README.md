# AI ChatBot

## Description

AI ChatBot is a Java-based conversational application that simulates human interaction through predefined responses. The chatbot can answer common questions, provide information about Java and OOP concepts, display the current date and time, and engage in basic conversations with users.

## Features

* Interactive chat interface
* Responds to greetings and common queries
* Answers questions about Java and OOP
* Displays current date and time
* Provides help and guidance to users
* Exit option using a simple command

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Java Time API
* Eclipse IDE

## Concepts Implemented

* Classes and Objects
* Methods
* String Handling
* Conditional Statements
* Loops
* User Input Handling
* Date and Time API

## How to Run

1. Open the project in Eclipse.
2. Run the `AIChatBot.java` file.
3. Type your messages in the console.
4. Enter `bye` to exit the chatbot.
