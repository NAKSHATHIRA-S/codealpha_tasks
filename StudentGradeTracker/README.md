# Student Grade Tracker

## Description

Student Grade Tracker is a Java-based application developed to manage and analyze student academic performance. The system allows users to enter student details and marks, calculate grades, and generate performance statistics.

## Features

* Add student records
* Store student names and marks
* Calculate grades automatically
* Display student details
* Calculate average marks
* Find highest and lowest scores
* Menu-driven console interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Eclipse IDE

## Concepts Implemented

* Classes and Objects
* Encapsulation
* Methods
* Loops
* Conditional Statements
* Collections Framework (ArrayList)

## How to Run

1. Open the project in Eclipse.
2. Run the `StudentGradeTracker.java` file.
3. Follow the menu options displayed in the console.
